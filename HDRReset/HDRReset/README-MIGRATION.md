# HDRReset WPF migration

这是基于已发布版本 `76772fbb1fe25d05f89f2d78734631de2187bc2b` 做的第一阶段 WPF/XAML GUI 迁移。

本版本的目标是：

- 保留原来的 DDC/CI HDR Photo 刷新逻辑
- 保留 30 分钟绝对时间计时逻辑
- 保留启动立即刷新
- 保留手动刷新
- 保留按 `1` 刷新
- 保留系统托盘
- 保留单实例
- 将 WinForms 主窗口替换为 WPF/XAML
- 不加入睡眠/唤醒监测
- 不加入第三方 UI 框架

## 重要

这是迁移测试版，不应直接覆盖现有稳定版本。

先确认可以正常编译、启动、托盘运行、手动刷新和自动刷新，再替换正式版本。
