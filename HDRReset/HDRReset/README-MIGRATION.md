# HDRReset：WPF 界面与双进程托盘架构

本版本保留原 WPF/XAML 界面及 HDR 刷新功能，并将托盘宿主与界面拆分为两个进程。两个进程通过本机命名管道通信，最终发布为同一个自包含单文件 `HDRReset.exe`。

保留的功能：

- DDC/CI HDR 模式刷新，支持 Photo、Movie、Game、TB400、Auto 五种模式
- HDR 模式、刷新间隔和语言设置按原有方式保存
- 默认 30 分钟自动刷新，应用刷新间隔后重新计时
- 启动立即刷新、手动刷新、数字键 `1` 刷新
- 托盘左键打开界面，右键菜单保留单一“刷新HDR”操作
- 最近 3 条刷新历史由托盘宿主保存在内存中，不写入硬盘
- 关闭 WPF 窗口只退出 UI 子进程，托盘宿主和刷新引擎继续运行
- UI 退出按钮退出整个程序
- 不加入睡眠/唤醒监测，不加入第三方 UI 框架

构建与运行说明见 `README-TWO-PROCESS.md`。在 Windows 上使用 .NET 8 SDK 执行 `publish.bat` 生成单 EXE。此源码包尚未在当前环境中实际编译运行，建议先验证后再替换现有稳定版本。
